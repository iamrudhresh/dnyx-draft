# Design System & UI Specifications

## 1. Design Philosophy
- **Aesthetic Excellence**: Vibrant, high-contrast, polished interface built for developers and researchers.
- **Glassmorphism & Micro-animations**: Subtle backdrop blur on headers and dialogs with smooth layout transitions powered by Framer Motion.
- **Dark Mode First**: Tailored deep dark palette (`#0d1117`, slate, zinc) with zero FOUC via `next-themes`.

## 2. Color Tokens
- `primary`: Modern Indigo / Cyan accents
- `background`: Adaptive light (`#ffffff`) and dark (`#090d16` / `#0d1117`)
- `muted`: Subdued text and border tones for clean readability
- `destructive`: Clean red for deletion / warning prompts

## 3. Typography
- **Editor**: Monaspace Neon / Fira Code / JetBrains Mono (monospaced with ligatures).
- **UI / Headings**: Inter / Outfit (clean sans-serif).
- **Prose**: Optimized reading line-height (1.6 - 1.8) and responsive heading scale.
