# Environment Variables

| Variable | Required | Description | Default |
| :--- | :--- | :--- | :--- |
| `NEXT_PUBLIC_APP_URL` | No | Base URL of the web application | `http://localhost:3000` |
| `SENTRY_DSN` | No | Sentry Project DSN for error monitoring | `""` |
| `KV_REST_API_URL` | No | Upstash / Vercel KV URL for snapshot sharing | `""` |
| `KV_REST_API_TOKEN` | No | Upstash / Vercel KV Token for snapshot sharing | `""` |
